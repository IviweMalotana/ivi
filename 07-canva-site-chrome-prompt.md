# 07 · Canva Site — Chrome Agent Prompt

You want to host your brand on your existing Canva site (replacing the current
`ivi-m.my.canva.site` content). Below is a ready-to-paste prompt for a **Chrome browser-AI agent**
— Perplexity **Comet**, **ChatGPT Atlas**, or **Gemini in Chrome** — that operates inside your
already-logged-in Canva and builds + publishes the site for you.

## How to use it

1. Open Chrome and make sure you're **logged into Canva** in that browser.
2. Open your browser-AI agent (Comet / Atlas / Gemini-in-Chrome) so it can see and act on the tab.
3. Paste **everything inside the code block below** as your instruction.
4. Watch it work; approve any confirmation prompts (publishing, permissions).
5. When it's done, check `ivi-m.my.canva.site` and tweak visually in Canva if you want.

> Note: browser agents can't always do pixel-perfect layout. The prompt tells it to get the
> **content, structure and clean style** right; you do a 10-minute visual polish in Canva after.

---

## If you'd rather not use a browser agent

The exact same site already exists as clean HTML in this repo — `assets/brand-hub.html`. Options:
- **Fastest:** open `assets/brand-hub.html` in a browser and rebuild those sections in Canva by
  eye (15–20 min).
- **Better long-term:** host `brand-hub.html` on a real domain (`ivimalotana.com`) via Netlify,
  Vercel or GitHub Pages — it's already responsive and theme-aware. Then the Canva site can just
  redirect there. Tell me and I'll set the repo up for one-click GitHub Pages hosting.

Either way, once the site's live, update the link in your LinkedIn (`06-content-and-outreach.md`)
and on your business cards.
