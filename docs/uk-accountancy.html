04 · case study

Case study

Emerald
Path

UK accountancy platform I built end to end in three months. Three steps.

01

Onboarding a client

Enter a company name. Companies House pulls the directors, share structure, filing history. SmartSearch runs the AML check. Adobe Sign or DocuSign sends the engagement letter. Billing kicks in on the firm's subscription.

Companies House API Inform Direct SmartSearch AML Adobe Sign DocuSign
02

The client's accounts data flows in

Xero, Sage or QuickBooks connect via OAuth (frontend-callback pattern so keys never touch a shared server). Bank transactions land continuously. The AI gateway categorises each transaction against the firm's chart of accounts and proposes journals. Every AI proposal cites the source transaction row. A partner reviews before anything books.

Xero API Sage API QuickBooks API AI gateway Python + AWS Lambda
03

Year-end filed

The FRS-102 statutory accounts engine builds full accounts from the bookkeeping. The iXBRL tagger reaches 100% coverage on the Xero demo company (deterministic, chart-of-accounts driven, not AI-guessed). CT600 corporation tax computes. VAT flows through HMRC MTD. Filed to HMRC and Companies House.

FRS-102 engine iXBRL @ 100% CT600 HMRC MTD Companies House filing Croner-i

05 · built with

Stack

Built
with.

Serverless-first. One operator runs the whole thing.

Frontend

React + TypeScript + Tailwind + Vite. Mobile-responsive design system with tokens and pre-commit checks. No-code page builder for firm-branded pages.

Backend

Python 3.12 on AWS Lambda. REST APIs, webhooks, event-driven pipelines on DynamoDB streams.

Data

Aurora PostgreSQL + DynamoDB. Per-tenant Postgres schemas with row-level security. Point-in-time restore on Aurora.

Infra

AWS Serverless. Lambda, Aurora, DynamoDB, Cognito, S3, CloudFront, WAF, CloudTrail, SES. SAM / CloudFormation IaC. eu-west-2.

AI

LLM gateway with grounded citation-backed generation. Per-phase model routing. Six custom Skills. Nine subagent definitions.

Integrations shipped

Xero, Sage, QuickBooks, HMRC MTD, Companies House, Inform Direct, IRIS Elements, Croner-i, SmartSearch AML, Adobe Sign, DocuSign, Freshdesk, Sumsub, GitHub OAuth, Cognito.

06 · the skill

Example skill

Month-end
commentary.

A real SKILL.md. Dropped in the repo, picked up by the pipeline. Partner edits it with no code.

.skills/month-end-commentary/SKILL.md example
--- name: month-end-commentary description: Draft a month-end commentary from a Xero P&L. Every claim points back to a source row. --- # Month-end commentary You draft a first pass. A partner reads it before it goes out. Never send it yourself. Never make up a number. ## What you get - The month's P&L, exported from Xero. - The client's engagement letter (tells you their industry). - The firm's voice guide at /voice.md. ## What you do 1. Read the P&L. For any line that moved > 15% or > £5,000, write ONE sentence about what changed. Tag it with the source row. 2. Group the sentences under: Revenue, Gross margin, Overheads. 3. Add an "outlook" line only if a trend runs three months. Otherwise write "nothing to flag this month". 4. Keep every source row visible. Partner clicks to check. ## What you never do - Invent a reason ("customer wins in Q3") unless it's in the notes file. - Use "significantly" without a number next to it. - Send it. Hand back to the partner. Leave the ticket in "For review".

07 · already safe

Precautions

Already
safe.

Every item below is live in Emerald Path today.

  • Three-layer tenant isolation. Per-firm Postgres schema + row-level security + an authorizer that gates every API call by firm membership. Verified by E2E tests on every PR.
  • AWS WAF fronting the API. Blocks SQLi, XSS attempts, bad bots before they reach the app.
  • Point-in-time restore on Aurora + CloudTrail on the account. Rollback to any second in the last 35 days. Every action logged with actor + timestamp.
  • Password reset hardened against brute force and code enumeration. Full BRD written before the code. Public writeup.
  • XSS sanitisation on all user-authored content. Byte-identity HTML round-trip tests catch regressions in the sanitiser.
  • API Gateway throttled with 429 retry and batching. Prevents a runaway job from taking down the account.
  • Every AI-generated line cites its source row. Nothing client-facing sends without a partner tapping OK.
  • Production database backups + tenant-isolation audit packaged as a reusable Skill a partner can run.
