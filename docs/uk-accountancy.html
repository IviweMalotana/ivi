04 · case study

Case study

Emerald
Path

A UK accountancy platform I built end to end in three months. Here it is in three steps.

01

Onboarding a client

Enter a company name. Companies House pulls directors, share structure and filing history. SmartSearch runs the AML check. Adobe Sign or DocuSign sends the engagement letter. Billing picks up on the firm's subscription.

Companies House API Inform Direct SmartSearch AML Adobe Sign DocuSign
02

Accounts data flows in

Xero, Sage or QuickBooks connect over OAuth, using a frontend-callback pattern so keys never touch a shared server. Bank transactions land continuously. The AI gateway categorises each transaction against the firm's chart of accounts and proposes journals, citing the source row for every proposal. A partner reviews before anything books.

Xero API Sage API QuickBooks API AI gateway Python + AWS Lambda
03

Year-end filed

The FRS-102 statutory accounts engine builds the full accounts from the bookkeeping. The iXBRL tagger hits 100% tag coverage on the Xero demo company — it's deterministic and chart-of-accounts driven, not AI-guessed. CT600 computes. VAT flows through HMRC MTD. It all files to HMRC and Companies House.

FRS-102 engine iXBRL @ 100% CT600 HMRC MTD Companies House filing Croner-i

05 · the stack

Stack

The
stack.

Serverless-first, so one operator can run the whole thing without a platform team behind them.

Frontend

React, TypeScript, Tailwind, Vite. A mobile-responsive design system with tokens and pre-commit checks, plus a no-code page builder for firm-branded pages.

Backend

Python 3.12 on AWS Lambda. REST APIs, webhooks, and event-driven pipelines over DynamoDB streams.

Data

Aurora PostgreSQL and DynamoDB. Per-tenant Postgres schemas with row-level security, point-in-time restore on Aurora.

Infra

AWS Serverless: Lambda, Aurora, DynamoDB, Cognito, S3, CloudFront, WAF, CloudTrail, SES. SAM / CloudFormation for the infra. eu-west-2.

AI

An LLM gateway with grounded, citation-backed generation. Per-phase model routing, six custom Skills, nine subagent definitions.

Integrations shipped

Xero, Sage, QuickBooks, HMRC MTD, Companies House, Inform Direct, IRIS Elements, Croner-i, SmartSearch AML, Adobe Sign, DocuSign, Freshdesk, Sumsub, GitHub OAuth, Cognito.

06 · a skill

Example skill

Month-end
commentary.

A real SKILL.md. Drop it in the repo, the pipeline picks it up, and a partner can edit it without touching code.

.skills/month-end-commentary/SKILL.md example
--- name: month-end-commentary description: Draft a month-end commentary from a Xero P&L. Every claim points back to a source row. --- # Month-end commentary You draft a first pass. A partner reads it before it goes out. Never send it yourself. Never make up a number. ## What you get - The month's P&L, exported from Xero. - The client's engagement letter (tells you their industry). - The firm's voice guide at /voice.md. ## What you do 1. Read the P&L. For any line that moved more than 15% or more than £5,000, write ONE sentence about what changed. Tag it with the source row. 2. Group the sentences under: Revenue, Gross margin, Overheads. 3. Add an "outlook" line only if a trend runs three months. Otherwise write "nothing to flag this month". 4. Keep every source row visible. Partner clicks to check. ## What you never do - Invent a reason ("customer wins in Q3") unless it's in the notes file. - Use "significantly" without a number next to it. - Send it. Hand back to the partner. Leave the ticket in "For review".

07 · what's locked down

Precautions

What's
locked
down.

Everything on this list is live in Emerald Path today, not a plan.

  • Three layers of tenant isolation: a per-firm Postgres schema, row-level security on top, and an authoriser that checks firm membership on every API call. E2E tests cover it on every PR.
  • AWS WAF in front of the API. SQLi, XSS attempts and bad bots get stopped before they reach the app.
  • Point-in-time restore on Aurora and CloudTrail across the account. Rollback to any second in the last 35 days, with every action logged against an actor and a timestamp.
  • Password reset hardened against brute force and code enumeration. A full BRD written before the code, published as a writeup.
  • XSS sanitisation on everything user-authored, with byte-identity HTML round-trip tests that catch regressions in the sanitiser.
  • API Gateway throttled with 429 retry and batching, so a runaway job can't take the account down.
  • Every AI-generated line cites the row it came from. Nothing client-facing goes out without a partner tapping OK.
  • Production database backups and a tenant-isolation audit, both packaged as a reusable Skill a partner can run on their own.
